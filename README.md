# ⚡ abidyow — Developer Portfolio & TJKT (Abid Taqiyudin)

Website portofolio dan profil pengembang dengan tema **Ultra-Premium Monochrome Cyber Dark**, efek glassmorphism modern, dan fitur interaktif profesional.

---

## ✨ Fitur & Keunggulan Baru
- 🖥️ **Tema Monokrom & Cyber Pro**: Palet hitam, putih, silver, dan sentuhan subtle neon glow yang elegan dan berkelas ala developer modern (Vercel / Linear / Apple Pro).
- 🌌 **Dynamic Particle Constellation**: Latar belakang kanvas partikel digital interaktif yang halus dan responsif.
- ⌨️ **Dynamic Typing Subtitle**: Teks animasi mengetik dinamis pada hero section untuk menampilkan berbagai kompetensi.
- 💻 **Developer Studio & Interactive Terminal**:
  - Tab TypeScript Config (`abidyow.profile.ts`)
  - Tab JSON Stack Overview (`stack.config.json`)
  - Tab Interactive Bash CLI (`help`, `bio`, `skills`, `school`, `contact`, `abidyow`, `date`, `secret`)
- 🔦 **Mouse Spotlight Card Glow**: Efek sorotan cahaya radial dinamis yang mengikuti kursor mouse pada setiap kartu.
- 🖼️ **Cyber Tech Photo Frame**: Bingkai foto profil futuristik dengan aksen bracket sudut, efek border glowing, dan floating tech badges.
- 📋 **Developer Spec Dossier**: Data diri terstruktur dengan tombol *One-Click Copy* (disertai feedback Floating Toast Alert).
- 🛠️ **Skill Matrix & Progress Bar**: Indikator tingkat keahlian web development, hardware komputer, dan jaringan LAN (TJKT).
- 🚀 **Showcase Proyek**: Kartu karya pilihan (Game Edukasi, Web Portfolio, Setup Lab LAN).
- 💬 **Quick WhatsApp Message Composer**: Form pesan cepat yang langsung terhubung ke WhatsApp.

---

## 💻 Teknologi yang Digunakan
- **HTML5 Semantic** : Struktur semantik dan aksesibilitas modern
- **Vanilla CSS3** : Design tokens, CSS variables, glassmorphism, responsive grid/flexbox
- **Vanilla JavaScript (ES6+)** : Logika terminal CLI, kanvas partikel, animasi kursor, dan clipboard handler
- **Google Fonts** : *Plus Jakarta Sans* (Modern Display) & *JetBrains Mono* (Code / Terminal)

---

## 🚀 Menjalankan Secara Lokal
Cukup jalankan web server sederhana (misal menggunakan Python):
```bash
python -m http.server 3000
```
Buka browser dan akses: `http://localhost:3000`
