# Landing Page Perkenalan Diri - Abid Taqiyudin

Website portofolio dan perkenalan diri sederhana yang dibuat menggunakan HTML5 dan CSS3 murni.

## 📌 Fitur
- **Hero & Profil**: Menampilkan foto profil dan perkenalan singkat.
- **Tentang Saya**: Deskripsi minat dalam dunia teknologi dan komputer.
- **Data Diri**: Informasi pribadi (Nama, Kontak, Email, Alamat, dll).
- **Skill**: Menampilkan keterampilan dasar komputer dan pemrograman web.
- **Kontak**: Tautan langsung ke Email dan WhatsApp.

## 💻 Teknologi yang Digunakan
- **HTML5** : Struktur halaman web
- **CSS3** : Styling dan tata letak responsif
- **Google Fonts** : Tipografi modern (Poppins)
